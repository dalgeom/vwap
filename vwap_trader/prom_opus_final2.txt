## SL 시뮬레이션 버그 — 모든 백테스트 무효화

### 버그 내용
```python
# 원래 코드 (잘못됨): 8h 후 종가 1번만 체크
cur_price = rows[nearest_idx]["c"]
if cur_price <= pos["sl"]:
    sl_hit = True

# 현실 (Bybit SL 주문): 매 15분봉 low/high가 SL 라인에 닿으면 즉시 발동
for r in future_candles:
    if direction == "long" and r["l"] <= sl:
        sl_hit = True; break
```

### 영향
| SL 체크 방식 | SL 비율 |
|-------------|--------|
| 원래 코드 (8h 종가) | 41.5% |
| 현실 (매봉 체크) | 83.2% |

기존 백테스트의 +1,254%, Sharpe 3.31, sensitivity 9/9 양수 — 전부 이 버그 때문에 나온 가짜 결과.

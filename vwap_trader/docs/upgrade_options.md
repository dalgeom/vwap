# 모멘텀 봇 업그레이드 옵션 (2026-05-15 정리)

기준: v3 42건 실측 데이터 (3.2건/시간, ~77건/일)

---

## 옵션 A: 데이터만 더 쌓기 (현행 유지)

- **변경**: 없음. v3 그대로 재가동
- **목표**: 50건 → 100건 도달
- **일 거래수**: ~77건
- **기대 EV**: -$22/건 유지 시 추가 -$1,300 예상 손실
- **장점**: 판단 근거 확실해짐. 42건 결론이 노이즈인지 패턴인지 검증
- **단점**: 돈 잃으면서 기다림. 이미 260건으로 큰 그림은 나왔음
- **적합**: "아직 확신이 없다. 42건이 우연일 수 있다"

---

## 옵션 B: 안전 필터만 적용 (보수적 개선) ← 1순위 추천

- **변경**: ① Short 제한 (BTC DOWN일 때만 Short) ② 유동성 필터 ③ 슬리피지 큰 코인 cooldown
- **구현 난이도**: 낮음 (config + 조건문 몇 줄)
- **일 거래수**: ~63건
- **기대 효과**: PF 0.784 → 0.85~0.95. "확실히 나쁜 거래" 제거
- **장점**: 구현 간단, 리스크 낮음
- **단점**: 근본 문제(진입 타이밍, RR 미달)는 해결 안 됨
- **적합**: "확실한 독만 빼고 지켜보겠다"

---

## 옵션 C: Pullback Entry만 적용 (구조적 개선) ← B 후 2순위

- **변경**: 시장가 즉시 진입 → signal 후 0.3 ATR pullback에 limit order, 3 bars 내 미체결 시 취소
- **구현 난이도**: 중간 (주문 로직 변경, 미체결 관리, 취소 로직)
- **일 거래수**: ~50건
- **기대 효과**: MFE=0 비율 25%→~10%. 실현 RR 0.95→1.05~1.15. PF 0.86→1.05~1.15
- **장점**: 전문가가 꼽은 "가장 impact 큰 단일 변경". 진입 슬리피지 + 꼭대기 진입 동시 해결
- **단점**: 구현 복잡도. fill 안 되면 놓친 거래 아쉬움. 검증에 100건+ 필요
- **적합**: "근본 원인을 고치고 싶다"

---

## 옵션 D: B + C 동시 적용 (풀 업그레이드)

- **변경**: 안전 필터 + Pullback Entry 동시
- **일 거래수**: ~41건
- **기대 효과**: PF 0.86 → 1.1~1.3. EV 양수 전환 가능성
- **장점**: 최대 개선폭
- **단점**: 변수 2개라 효과 분리 불가. 동시 수정 → 버그 위험
- **적합**: "빨리 수익 전환하고 싶다"

---

## 옵션 E: A/B 테스트 (가장 체계적)

- **변경**: 안전 필터 + Pullback Entry를 50% 확률로 적용 (랜덤 분배)
- **일 거래수**: ~50건
- **기대 효과**: 동일 환경에서 pullback vs 시장가 직접 비교
- **장점**: 과학적 검증. "pullback이 정말 나은가?" 데이터로 증명
- **단점**: 구현 가장 복잡. 반은 여전히 나쁜 방식. 100건+ 모으려면 3-4일
- **적합**: "감이 아니라 데이터로 결정하고 싶다"
- **비유**: 같은 수리인데 한쪽만 교체해서 비교 실험

---

## 옵션 F: 전략 피벗 (급진적, 처음부터 재설계)

- **변경**: BTC 4h EMA 방향 필터 + pullback entry 전용 + ATR 비율 임계값(percentile 대신) + BEP trailing + 유니버스 축소($50M+, 스프레드 <0.03%)
- **구현 난이도**: 높음 (2-3일 개발 + 2-3일 검증)
- **일 거래수**: ~18건 (매우 selective)
- **기대 효과**: PF 1.3+ 목표. 완전히 다른 봇
- **장점**: 260건에서 배운 것 전부 반영. 근본적 재설계
- **단점**: 기존 데이터와 비교 불가. 사실상 새 봇. 개발 기간 중 수집 중단
- **적합**: "현재 전략은 한계가 보인다. 갈아엎겠다"
- **비유**: 새 차 사기. B/C/D 해보고 안 되면 그때 가도 늦지 않음

# 횡방향 상대강도 모멘텀(Cross-Sectional Momentum) — Gate 1 소급 채점 설계

> 최초 작성: 2026-07-20 (DEV PC 세션, 브레인스토밍 산출물)

> 관련: PLAN.md §1.1·§7.5·§8.9+·§10(되돌림 2 NO-GO 직후)·§11
> 선행: 저변동 개별 MR = NO-GO, 쌍 스프레드 MR = NO-GO(가설 맞으나 엣지<비용). 되돌림 계열 2연패 → 모멘텀 가족으로 전환.

## 0. 배경
모멘텀 봇은 단일 전략(고변동 파도). 보완재로 되돌림 2종을 시도했으나 (개별=엣지 없음 / 상대=엣지 있으나 비용에 미달) 둘 다 NO-GO. 교훈: 되돌림 계열은 벽. 우리 봇이 이미 입증한 **모멘텀 엣지**를 다른 형태(횡방향)로 쓰되, 롱-숏 시장중립으로 보완성을 확보.

## 1. 가설
**"최근 강했던 알트는 계속 강하고, 약했던 알트는 계속 약하다"**(상대 지속, Jegadeesh-Titman). 절대 방향이 아니라 **알트 간 상대 순위**에 베팅. 강한 상위 N 롱 + 약한 하위 N 숏 = 시장 공통움직임 상쇄.

## 2. 왜 3연패와 다르고 왜 보완인가
- **되돌림 아님**: 개별·쌍 되돌림(2 NO-GO)과 반대 — **지속**에 베팅. 봇이 입증한 모멘텀 엣지의 사촌.
- **보완성**: 롱-숏 시장중립이라 방향장이 아니라 **코인 간 분산(dispersion)**에서 벎 — 조용한 장에서도 코인들이 서로 다르게 움직이면 수익. 시간축 모멘텀(같은 가뭄)보다 나음.

## 3. 스코프 (Gate 1만)
3단 게이트 중 Gate 1(소급 채점)만. 봇 코드·config·실주문 무변경. 통과해야 Gate 2 설계.

## 4. 메커니즘 (포트폴리오형 — 앞선 둘과 채점 구조 다름)
- **순위**: 각 리밸런싱 시점 t에 알트를 **과거 `lookback` 수익률**(`close[t]/close[t−lookback] − 1`)로 정렬
- **바스켓**: 상위 N 롱 + 하위 N 숏, 등가중 달러중립
- **보유**: `rebalance` 주기마다 갱신. 개별 손절 없음(포트폴리오 재구성)
- **주기 손익**: `net = mean(롱 보유수익) − mean(숏 보유수익) − 회전비용`
  - 롱 보유수익 = `close[t+reb]/close[t] − 1`, 숏은 부호 반대(숏 이익 = −보유수익)
  - **회전비용**(바뀐 종목만): `((신규롱 + 신규숏)/N) × (FEE + 2×SLIP) × 100` — 유지 종목 무과금, 완전교체 시 최대 0.42%p, 무변동 시 0
- **백테스트**: 1h 종가만(경로의존 0, 250일 캐시 재사용). 각 리밸런싱 주기 = **1개 관측** → 수익률 시계열

## 5. 사전등록 그리드 (자율 확정, 실행 前 봉인)
| 파라미터 | 후보 | 의미 |
|---|---|---|
| `lookback_h` | {72, 168, 336} | 3일 / 7일 / 14일 (단기반전 회피 3일↑) |
| `rebalance_h` | {24, 72} | 갈아끼우는 주기 |
| `basket_n` | {3, 5} | 롱/숏 각 N |

= 3×2×2 = **12조합**, Bonferroni 0.05/12 ≈ 0.00417. skip=0·등가중 고정. 유니버스=알트(min_vol $10M)−BTC. 기간=1h 전체(~250일).

## 6. 판정 기준 (사전등록, 3중 AND — 포트폴리오형 지표)
1. **수익성**: 주기별 net 수익 **연율 Sharpe ≥ 1.0**(거래할 가치 표준 문턱) **그리고** 평균>0 부트스트랩 `P(≤0) < 0.05/12 ≈ 0.00417`
   - 연율화: `Sharpe = mean(net)/std(net) × sqrt(365×24/rebalance_h)`
2. **강건성**: (a) 12조합 중앙값 Sharpe > 0, (b) 양수(Sharpe>0) 조합 ≥ 60%, (c) 최적 칸 각 축 ±1 이웃 양수
3. **보완성**: (a) 일별 바스켓 수익의 모멘텀봇 일별손익 상관 < 0.3, (b) 총이익의 ≥50%가 모멘텀 저활동기
- **표본 게이트**: 최적 조합 주기 관측 ≥ 60개(250일÷주기라 표본 작음 — 미만 시 "잠정")

셋 다 통과 → GO. 하나라도 실패 → NO-GO. 최종 리포트를 사용자가 판단.

## 8. 테스트 전략
- `xsmom_rank`(순수): past_return 계산, select_basket(상위/하위 N), period_pnl(롱-숏 net + 회전비용), 무변동 0비용·완전교체 최대비용, 방향(숏 부호) 검증
- 재사용 유닛은 기존 테스트로 커버
- TDD

## 9. 명시적 비목표 (YAGNI)
- 봇 로직·config·실주문 변경 없음
- skip 기간·리스크가중·변동성조정·다중 시간축 없음(Gate 1은 가설 생사만)
- 실시간 스캔·주문 코드 없음

## 10. 위험·한계
- **★ 표본 작음**(주기당 1관측 → 60~250개) = 통계 신뢰 낮음, "잠정" 가능성 높음. Sharpe 신뢰구간 넓음.
- **회전비용**: 리밸런싱 잦으면 비용 폭증 — rebalance 그리드가 검정
- **단기반전 위험**: lookback 짧으면 모멘텀 아닌 반전(그래서 3일↑)
- **XS 모멘텀 엣지 감쇠 가능**: 학계 강건하나 최근 약화 보고 — Gate 1이 우리 시장·기간서 실측
- **종가 리밸런싱 근사**: 주기 종가로 진입·청산 가정(실제 체결 슬리피지는 비용에 반영)
- **생존편향**: 현재 상장 알트만(상폐=약자→숏 승자였을 것, 누락은 비관 방향=안전)
- ⚠️ 3연패했듯 이것도 죽을 수 있음.

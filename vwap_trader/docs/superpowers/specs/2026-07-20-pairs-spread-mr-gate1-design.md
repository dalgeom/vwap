## 0. 배경 — 왜 이 전략인가

모멘텀 봇은 단일 전략(고변동 파도)이라 곡선이 계단식이고 저변동·횡보장에서 가뭄이 길다. 몬테카를로: 상관 낮은 2호 전략을 자본 분할로 더하면 기대수익 불변·최악낙폭 −32~42%. 1호 후보였던 **저변동 개별 코인 되돌림은 NO-GO**(잔파도가 되돌림 아닌 소추세로 판명). 그 실패가 설계 공간을 좁혀줌: **개별 코인은 안 되돌아오지만 두 코인의 격차(spread)는 되돌아올 수 있다** — 공통 시장 움직임이 롱-숏에서 상쇄되기 때문.

## 1. 가설 (한 줄)

**"알트코인이 BTC 대비 비정상적으로(±zσ) 벌어지면 그 격차는 곧 좁혀진다."** 개별 코인의 절대 되돌림이 아니라 **BTC 대비 상대 되돌림**. 롱-숏 시장중립이라 알트의 고유(idiosyncratic) 이탈만 베팅.

## 2. 왜 MR 실패와 다르고, 왜 모멘텀을 보완하나

- **MR 실패 무관**: MR은 "튄 코인이 절대가격으로 되돌아온다"였고 반증됨(잔파도=소추세). 여기선 **BTC와의 격차**가 대상 — BTC와 알트가 **둘 다 추세로 가도** 격차는 좁혀질 수 있음(공통 추세가 롱-숏에서 소거). 근본적으로 다른 메커니즘.
- **보완성**: 시장중립이라 방향장(모멘텀의 먹이)이 아니라 **횡보·조용한 장(모멘텀의 가뭄)**에서 알트 간 상대 오차로 벎. 이론상 모멘텀과 상관 낮음 — Gate 1이 실측 검정.

## 3. 스코프 (Gate 1만)

3단 게이트 중 **Gate 1(소급 채점)만.** 봇 코드·config·실주문 변경 0. 산출물 = 판정 리포트. 통과해야 Gate 2(forward 계측) 설계. §1.1: 가설이 백테스트에서 죽으면 봇 불필요.

## 4. 메커니즘

- **스프레드**: `s = log(alt) − log(BTC)` (달러중립 로그 비율, β 피팅 없음 → knob 안 늘어남)
- **신호**: s의 rolling z-score(창 n). `|z| ≥ z_entry` 진입.
  - `z>0`(알트 과열) → **short_spread**(알트 숏 + BTC 롱)
  - `z<0`(알트 과냉) → **long_spread**(알트 롱 + BTC 숏)
- **출구**(MR 교훈 반영 — 부분복귀 목표):
  - **target**: z가 `z_target`(부분복귀)까지 회귀 시 익절 (short_spread: z↓≤z_target / long_spread: z↑≥−z_target)
  - **stop**: z가 `z_stop`까지 더 벌어짐 시 손절 (short: z≥z_stop / long: z≤−z_stop) — 유일한 큰 위험
  - **time**: `max_hold` 내 미회귀 시 청산
  - 판정 해상도 = **1h봉 종가 기반 z**(스프레드 intra-bar high/low는 두 자산 비동기라 부정의 → 종가 z가 정직·일관, 경로독립)
- **손익**: 달러중립. `pnl_log = ±(s_entry − s_exit)`(short_spread면 +부호). `pnl_pct = pnl_log×100 − 총비용`
  - **총비용 = 2다리 × (왕복수수료 + 왕복슬리피지)** = 2×(0.0011 + 0.0010) = **0.42%p** (★쌍 거래의 핵심 역풍)

## 5. 사전등록 그리드 (assistant 자율 확정, 실행 前 봉인)

스프레드는 개별 가격보다 느리게 반전하므로 창·보유를 길게.

| 파라미터 | 후보 | 의미 |
|---|---|---|
| `n` (rolling, 1h봉) | {24, 72} | 1일 / 3일 |
| `z_entry` | {2.0, 2.5} | 진입 이탈(σ) |
| `z_target` | {0.0, 0.5, 1.0} | ★부분복귀 목표(MR 교훈) |
| `z_stop` | {3.5} | 고정(MR서 3.5/4.0 무차별) |
| `max_hold_h` | {24, 72} | 시간제한(시간) |

- 조합 수 = 2×2×3×1×2 = **24조합** → Bonferroni 0.05/24 ≈ 0.00208
- **앵커 = BTC 단일**(그리드 미포함; BTC는 유일한 자연 시장앵커라 마이닝 아님. ETH 앵커는 향후)
- **유니버스** = 모멘텀과 동일(min_vol $10M) − BTC ≈ 50 알트
- 백테스트 기간 = 확보 가능한 1h 전체(~250일, MR과 동일 캐시 재사용)

## 6. 판정 기준 (사전등록, 3중 AND — 실행 前 봉인)

1. **수익성**: 최적 조합 **건당 순EV ≥ +0.5%**(2다리 마찰 0.42% + 여유), 부트스트랩 `P(순EV≤0) < 0.05/24 ≈ 0.00208`
2. **강건성**: (a) 24조합 중앙값 EV > 0, (b) 양수 조합 ≥ 60%, (c) 최적 칸의 각 축 ±1 이웃 전부 양수
3. **보완성**: (a) 총이익의 ≥ 50%가 모멘텀 저활동기, (b) 일별 손익 모멘텀 상관 < 0.3
- **표본 게이트**: 최적 조합 진입 ≥ 100건이어야 decisive. 미만 시 "잠정".

셋 다 통과 → **GO**(Gate 2 설계 권고). 하나라도 실패 → **NO-GO**(폐기, §10 기록). 최종 GO/NO-GO 리포트를 사용자가 판단.

## 7. 구조 — harness 재사용

MR harness(`mr_*.py`)를 최대 재사용. 신규는 스프레드 계산·오케스트레이터만.

```
[사전등록] pairs_config.py (그리드·판정임계, 실행 前 커밋)
[재사용]   mr_signal.zscore (스프레드 계열에 그대로) · mr_score.* (집계·부트스트랩·보완성) · mr_data.fetch_1h_history (1h 캐시)
[신규]     pairs_spread.py  — 스프레드 계열 s=log(alt)−log(BTC), forward z 정렬 (순수)
[신규]     pairs_exit.py    — z 기반 target/stop/time 청산 (순수)
[신규]     pairs_gate1.py   — 오케스트레이터 + 판정 + 리포트
```

## 8. 테스트 전략

- `pairs_spread`·`pairs_exit`(순수함수): 합성 계열로 단위테스트 — 스프레드 계산, z 부호별 진입방향, target/stop/time 우선순위, 방향 대칭, 비용 반영
- 재사용 유닛(zscore·mr_score)은 기존 테스트로 커버됨
- TDD: 실패 테스트 → 최소 구현 → 통과

## 9. 명시적 비목표 (YAGNI)

- 봇 로직·config·실주문 변경 없음
- ETH/다중 앵커·β 회귀 헤지·동적 사이징·부분청산 없음(Gate 1은 가설 생사만)
- 실시간 스캔·주문 코드 없음(순수 소급)

## 10. 위험·한계

- **★ 수수료 2배(0.42%p)가 최대 역풍** — 상대 오차가 이를 넘을 만큼 큰지가 관건. MR보다 오히려 불리할 수 있음.
- **BTC 다리 쏠림**: 모든 쌍이 BTC를 반대편에 쥠 → 실전 시 BTC 포지션 합산으로 시장중립 깨질 수 있음. Gate 1 백테스트는 **쌍 독립 가정**(각 쌍을 별도 단위로 채점) — 이 한계 리포트 명시. 실전(Gate 3)에선 BTC 순노출 상한 필요.
- **종가 해상도**: intra-bar 무시. target/stop 모두 종가 판정이라 대칭(편향 작음)이나, 급변 시 stop 미끄러짐 과소평가 가능 → EV 다소 낙관. 리포트 명시.
- **생존편향**: 현재 상장 알트만. 상폐 알트(대개 BTC 대비 폭락 후 소멸)는 short_spread 승자였을 것 → 누락은 비관 방향(안전).
- ⚠️ MR처럼 깨끗이 죽을 수 있음. harness는 빠른 답만 줄 뿐 GO 보장 아님.

# 저변동 평균회귀(Mean-Reversion) 전략 — Gate 1 소급 채점 설계

> 최초 작성: 2026-07-20 (DEV PC 세션, 브레인스토밍 산출물)
> 상태: **설계 승인됨 → 구현 계획 대기**
> 관련: PLAN.md §1.1(방법론 철학)·§7.5(더하기식 개선)·§8.9+(되감기 백테스트 강등)·§11(사전등록)

## 0. 배경 — 왜 이 전략인가

현 모멘텀 봇은 **단일 전략**이다(가설 1·신호 1·출구 1·먹이 1=고변동 파도). 수익이 잭팟 소수에 몰려 자본곡선이 계단식이고, 가뭄(저변동·횡보장)에 무수익 구간이 길다(6월 138건 +$574 실증). 단일 전략 내부에서 곡선을 매끄럽게 만드는 길은 수학적으로 잠겨 있다(출렁임의 원천=수익의 원천=잭팟이라, 출렁임을 깎으면 수익도 깎임 — 부분익절 등 4회 기각). 유일한 경로는 **가뭄이 겹치지 않는 두 번째 전략을 더해 계곡을 서로 메우는 것**.

몬테카를로(275건 실측 분포 재표집): 독립 전략 2개·자본 절반씩 배분 시 최악낙폭 −42%(상관 0.5면 −32%), 기대수익 불변. 이 전략의 **역할 = 가뭄 메우기 보완재**(작은 사이즈, Gate 3에서 확정).

## 1. 이 전략이 무엇인가 (한 줄 가설)

**"저변동 코인에서 가격이 이동평균에서 비정상적으로(±Nσ) 벌어지면 그것은 과잉반응이고, 곧 이동평균으로 되돌아온다."** 모멘텀(큰 파도=지속)의 **정반대 가설**. 위로 튀면 매도, 아래로 빠지면 매수(역방향 진입) → 평균 복귀 시 익절.

이 전략의 사냥터는 v8 게이트가 모멘텀에게 **차단하는 바로 그 칸**(저변동)이다. 모멘텀 데이터가 "저변동 칸엔 모멘텀 잭팟이 없다"(EV −34·WR 22%)고 확인해준 그 버려진 칸이, 되돌림의 사냥터다 → **먹이가 겹치지 않음 = 가뭄 상관 낮음**.

## 2. ★ 왜 이 백테스트는 §8.9+ 강등 대상이 아닌가 (핵심 논거)

되감기 백테스트 4종(track_f1·track_cap·track_shadow·backtest_be)이 2026-07-08 강등된 이유는 **"1분봉 되감기가 모멘텀의 추적익절 경로를 재현 못 해 잭팟(fat-tail)을 뭉갠다"**(기준선 재현율 5~9%). 잭팟은 봉내 경로에 민감한 추적손절의 산물이라 저해상도 되감기로 파괴된다.

**되돌림은 추적익절이 없다. 고정 목표가 + 고정 손절 = 경로 독립.** 필요한 정보는 "목표에 먼저 닿았나, 손절에 먼저 닿았나" 뿐이고 1분봉으로 충실히 판정된다(동봉 동시 도달 시 **손절 우선**의 보수 가정만 지키면 됨). fat-tail 잭팟 구조가 없으니 뭉갤 것도 없다. → **모멘텀에선 못 믿을 백테스트가 되돌림에선 믿을 만하다.** 이것이 되돌림을 1호 확장 후보로 고른 숨은 이점.

## 3. 스코프 (이 스펙의 범위 = Gate 1만)

검증은 **3단 게이트**로 진행하되, 이 스펙은 **Gate 1만** 다룬다(§1.1: 가설이 백테스트에서 죽으면 봇 코드는 한 줄도 불필요).

- **Gate 1 (이 스펙)**: 과거 klines로 되돌림 신호를 생성·채점 → EV 양수·강건·보완적인지 판정
- Gate 2 (통과 시 별도 스펙): forward 가상체결 계측(무자본, 사전등록)
- Gate 3 (통과 시 별도 스펙): 데모 소액 → 실계좌 소액 슬리피지 계측

**봇 코드·config·실주문 변경 0.** 산출물 = 판정 리포트 + 사전등록 기록.

## 4. 구조 — 4개 순수 유닛 + 1개 사전등록 문서

```
[사전등록 문서 §7]  ← 실행 前 작성·커밋: 가설·파라미터 그리드·판정기준 못박음
      │
[유닛1 데이터층]  universe 과거 1h(신호)+1m(청산판정) klines 수집·캐시
[유닛2 신호생성]  각 코인·각 1h봉: z=(close−MA_n)/std_n. 이중필터 통과 시 fire(역방향)
[유닛3 청산시뮬]  진입봉부터 1m 전진: 목표(z=0)·손절(z=±z_stop)·시간제한. 동봉=손절우선. 수수료.
[유닛4 채점]      EV·WR·PF·부트스트랩CI·레짐별·코인별 + 모멘텀 가뭄기 상관
```

각 유닛은 한 책임·잘 정의된 인터페이스·독립 테스트 가능. 파일은 신규 `mr_*.py`로 분리(모멘텀 코드 불간섭).

## 5. 각 유닛 명세

### 유닛 1 — 데이터층 (`mr_data.py`)
- **책임**: 유니버스 과거 klines 수집·로컬 캐시
- **입력**: 심볼 목록(모멘텀과 동일 유니버스, min_vol $10M로 시작), 기간
- **출력**: `{symbol: {"1h": [(ts,o,h,l,c,v)...], "1m": [...]}}`, 파일 캐시(재실행 재사용)
- **의존**: pybit public klines (`get_kline`). 수집 패턴은 `backtest_delayed_entry.py`·`track_shadow.py` 재사용
- **⚠️ 제약**: 데모 1m klines 보관 한계 → 뽑히는 기간만(수 주~수개월). 표본 크기 제약이라 리포트에 명시. 1h는 더 길게 가능.

### 유닛 2 — 신호 생성 (`mr_signal.py`, 순수함수)
- `zscore(closes, n) -> float`: 종가 배열 → 최신 z (MA_n, 표본표준편차 std_n). 데이터 부족 시 None.
- `fires(z, atr_pct, btc_4h_ret, coin_trend, cfg) -> (bool, direction|None)`:
  - 1차: `|z| >= cfg.z_entry` → `z>0`이면 `"short"`(과열 fade), `z<0`이면 `"long"`(과매도 fade)
  - **이중 필터**(떨어지는 칼날 방어):
    - ① 저변동 게이트: `atr_pct < cfg.atr_ceiling` (이미 크게 흔들리는 코인은 fade 금지)
    - ② 추세 차단: `abs(btc_4h_ret) < cfg.btc_trend_max` **그리고** 코인 선행추세가 강하지 않을 것(강추세장 fade 금지)
  - 셋 다 통과해야 fire. 부작용 없음(순수).

### 유닛 3 — 청산 시뮬 (`mr_exit.py`, 순수함수)
- `simulate(entry_price, direction, ma_at_entry, sigma_at_entry, cfg, future_1m) -> (exit_price, reason, hold_min)`:
  - **목표가(target)**: 되돌림 방향으로 `ma_at_entry`(=z 0) 도달 시 익절, reason `"target"`
  - **손절(stop)**: 진입 반대로 `z = ±cfg.z_stop` 해당 가격(`ma ± z_stop*sigma`) 도달 시 컷, reason `"stop"` — **유일한 큰 위험, 하드캡**
  - **시간제한**: `cfg.max_hold_min` 내 미복귀 시 마지막 종가 청산, reason `"time"`
  - **동봉 목표+손절 동시 포함**: **손절 우선**(look-ahead 금지·보수 가정)
  - **수수료**: 왕복 taker(모멘텀과 동일 상수 `0.00055*2`) 반영
- 반환값은 손익 계산에 그대로 투입(별도 pnl 헬퍼는 유닛4).

### 유닛 4 — 채점 (`mr_score.py`)
- **집계**: n, WR, EV, PF, 출구별(target/stop/time) 분해, 레짐별, 코인별
- **부트스트랩**: 10k 재표집 → EV 95% CI, P(EV≤0)
- **★ 보완성 검정**: 각 되돌림 거래의 진입 시각을, 모멘텀 봇의 "가뭄"(정본 trades에서 신호 없는 저활동 구간)과 대조 → 수익의 몇 %가 모멘텀 가뭄기에 발생했는지 정량화

## 6. 판정 기준 (사전등록, 3중 AND)

**실행 前**에 못박는다. 결과를 보고 기준을 고치는 것은 금지(§11 규율).

1. **수익성**: 최적 조합 `EV > 수수료·슬리피지 여유분`(구체 임계는 §7에서 수치 확정), 부트스트랩 `P(EV≤0) < 0.05 / 조합수`(Bonferroni)
2. **강건성**: 최적 칸의 **이웃 파라미터 조합들도 함께 양수** — 단일 럭키 칸이면 과최적화로 **기각**
3. **보완성**: 수익의 상당분(사전 지정 비율)이 **모멘텀 가뭄기**에 발생 — 상관 낮음 확인

셋 다 통과 → Gate 2 설계 착수. **하나라도 실패 → 기각·기록·종료**(되돌림 폐기, §10 이력에 남김).

## 7. 사전등록 파라미터 그리드 (실행 前 확정)

| 파라미터 | 후보값 | 의미 |
|---|---|---|
| `n` (MA/std 창) | {20, 50} | 이동평균 기간(1h봉) |
| `z_entry` | {2.0, 2.5, 3.0} | 진입 이탈 문턱(σ) |
| `z_stop` | {3.5, 4.0} | 하드 손절(σ) |
| `atr_ceiling` | {1.0, 1.5} | 저변동 게이트 상한(%) |
| `max_hold` | {6h, 12h} | 시간제한 |

- 조합 수 = 2×3×2×2×2 = **48조합** → Bonferroni 유의수준 = 0.05/48 ≈ 0.00104
- `btc_trend_max`(추세 차단 문턱)는 모멘텀 v8의 `max_btc_4h_atr` 근방에서 단일값 고정(그리드 미포함, 다중검정 폭증 방지)
- 수수료·슬리피지 여유분 임계: **왕복 수수료(0.11%) + 보수 슬리피지 가정(0.1%) = 최소 0.21% 이상의 평균 이익률**이어야 EV 유효로 인정(구현 시 코인 tick·평균 목표폭 대비 재확인)

## 8. 테스트 전략

- **유닛 2·3(순수함수)**: 합성 캔들 단위테스트 — z 계산 정확도, 목표/손절 우선순위, **동봉 tie-break(손절 우선)**, 수수료 반영, 방향별(long/short) 대칭
- **유닛 4**: 알려진 손익 배열로 EV/PF/부트스트랩/보완성 검증
- **유닛 1(데이터층)**: 소량 실호출 스모크 1회(네트워크)
- TDD: 각 순수함수는 실패 테스트 → 최소 구현 → 통과 순

## 9. 명시적 비목표 (YAGNI)

- 봇 로직·실주문·config 변경 **없음**
- 부분청산·동적사이징·다중 시간축·복합신호 **없음**(Gate 1은 가설 생사 판정만)
- Gate 2/3 설계·구현 **없음**(통과 후 별도 스펙)
- 실시간 스캔·주문 코드 **없음**(순수 소급 연구)

## 10. 위험·한계

- **데이터 지평**: 데모 1m klines 보관 한계로 표본 기간이 짧을 수 있음 → 표본 부족 시 "판정 유보"도 정당한 결론(§1.1: 표본이 factor보다 귀함)
- **생존편향 없음 확인**: 유니버스는 현재 상장 코인이라 상장폐지 코인 누락 가능 — 저변동 되돌림에선 폐지 코인이 대개 급락형이라 낙관 편향 방향. 리포트에 명시.
- **레짐 종속**: 백테스트 기간의 레짐(주로 고변동장)이 되돌림에 불리했을 수 있음 → 레짐별 분해로 확인
- **1m 근사**: 목표·손절이 같은 1m봉 안이면 손절 우선 가정이 실제보다 비관적 → EV 하한 추정(보수적이라 안전)

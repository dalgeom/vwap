## 0. 배경 — 왜 펀딩인가
2호 전략 3연패(개별MR·쌍MR·XS모멘텀)의 통찰: **이 시장 수익은 죄다 소수 알트 잭팟 펌핑에 수렴** → 어떤 가격 기반 전략도 그 펌핑을 잡아 본진(모멘텀봇)과 상관됨. XS모멘텀이 실증(이익 62%가 LAB·ESPORTS=봇 잭팟코인). ∴ 진짜 보완재 = **가격 방향이 아닌 엣지원**. perp의 **펀딩(8h마다 롱↔숏 현금흐름)**이 유일한 후보 — 알트 펌핑과 무관한 캐시플로.

## 1. 가설
**"펀딩 높은 코인 숏 / 낮은(음수) 코인 롱으로 걷는 펀딩이, 그 대가로 지는 가격 위험을 넘는다."** 시장중립 롱-숏. 엣지원 = 펀딩 현금흐름(가격 아님).

## 2. 왜 3연패와 다르고 왜 보완인가
- **가격 아님**: 순위 신호가 펀딩률(가격 momentum/reversion 아님). 알트 펌핑과 다른 원천.
- **보완성**: 시장중립 + 펀딩 캐시플로라 방향장·펌핑과 무관 — Gate 1이 모멘텀봇 상관 실측.
- **정직한 위험**: 펀딩 높은 코인 = 롱 몰린 펌핑 코인이라 숏하면 가격 역행 공산(스팀롤러 앞 동전). 걷는 펀딩 < 가격 손실이면 죽음. 이게 핵심 검정.

## 3. 스코프 (Gate 1만)
봇 무변경. 소급 채점만. 통과해야 Gate 2 설계.

## 4. 메커니즘 (포트폴리오형)
- **순위**: 리밸런싱 시점 t에 알트를 펀딩 신호(`rank_lookback`=스팟 or 단기평균)로 정렬
- **바스켓**: 펀딩 **최고 N 숏** + **최저(음수) N 롱**, 등가중 달러중립
- **주기 손익**(t→t_next): `net = 걷은펀딩 + 가격드리프트 − 회전비용`
  - 걷은펀딩 = mean_long(−Σfunding) + mean_short(+Σfunding), 보유기간 8h 정산 합. (롱은 펀딩<0일 때 받음, 숏은 펀딩>0일 때 받음)
  - 가격드리프트 = mean(롱 price ret) − mean(숏 price ret)  ← **필수 포함, 진짜 위험**
  - 회전비용 = ((신규롱+신규숏)/N)×(FEE+2×SLIP)
- **★ 진단**: 주기별 **펀딩 기여 vs 가격 기여** 분해 기록 → "펀딩이 가격 역행을 이기나" 직접 확인
- **백테스트**: 펀딩 8h 클럭 + 1h 종가(캐시). 경로의존 0.

## 5. 사전등록 그리드 (자율 확정, 실행 前 봉인)
| 파라미터 | 후보 | 의미 |
|---|---|---|
| `rank_lookback_h` | {8, 72} | 스팟(직전 펀딩) / 3일 평균 |
| `rebalance_h` | {8, 24, 72} | 갈아끼우는 주기(8h 배수) |
| `basket_n` | {3, 5} | 롱/숏 각 N |

= 2×3×2 = **12조합**, Bonferroni 0.05/12 ≈ 0.00417. 유니버스=알트(min_vol $10M)−BTC. 기간=펀딩 확보분(~250일 목표, 코인당 8h×750≈4콜).

## 6. 판정 기준 (사전등록, 3중 AND — XS와 동일 골격)
1. **수익성**: 주기 net 연율 Sharpe ≥ 1.0 **그리고** 평균>0 부트스트랩 P(≤0) < 0.05/12
2. **강건성**: 중앙값 Sharpe > 0, 양수 조합 ≥60%, 최적 이웃 양수
3. **보완성**: 일별 모멘텀 상관 < 0.3, 가뭄기 이익 ≥50%
- 표본 게이트: 최적 조합 주기 ≥ 60개. 미만 "잠정".
- ★ **부수 진단(판정 무관, 참고)**: 최적 조합의 펀딩기여가 net의 대부분이어야 "진짜 캐리". 가격기여가 net을 지배하면 캐리 아닌 가격베팅(리포트 명시).

셋 다 통과 → GO, 아니면 NO-GO. 사용자 판단.

## 8. 테스트 전략
- `fund_rank`(순수): funding_signal(스팟/평균), period_carry_pnl(펀딩+가격 분해·회전비용·숏 부호), 무회전 0비용
- 재사용 유닛은 기존 테스트
- `fund_data`: 소량 실호출 스모크

## 9. 명시적 비목표 (YAGNI)
- 봇 무변경. 변동성가중·다중신호 없음. 실시간 코드 없음.

## 10. 위험·한계
- **★ 가격 위험이 펀딩 삼킬 공산** — 핵심 검정 대상(폐기된 펀딩 역추세가 방향으로 죽은 것과 별개지만 경고)
- **표본 작음**(주기당 1관측) = 잠정 가능성
- **펀딩 데이터 지평**: 8h×제한 — 250일 미만이면 표본↓, 리포트 명시
- **생존편향**: 현재 상장 알트만
- **데모 펀딩 = 실제 정산 근사**(데모가 실펀딩 반영하는지 불확실 — Gate 3서 실계좌 확인 필요)
- ⚠️ 3연패했듯 죽을 수 있음.

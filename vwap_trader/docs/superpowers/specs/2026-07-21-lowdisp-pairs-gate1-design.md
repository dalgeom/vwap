# 저분산 조건부 쌍 스프레드 되돌림 — Gate 1 설계

> 최초 작성: 2026-07-21 (DEV PC, Track 2)
> 상태: **⛔ NO-GO 기각 (2026-07-21, 사진판정 근소차)** — ★국면분리 16조합 전부 통과(저분산 EV +0.16% vs 고분산 −0.65%, 분리 +0.81%p): 가설(저분산서 되돌림 잘됨) 강력 검증. 그러나 최적 저분산 net EV +0.159%(승률 61%·PF 1.17)가 P(≤0)=0.0034로 Bonferroni 0.003125 근소 미달 + pairs 2차검정 페널티 → 전략으론 얇아 NO-GO. 되돌림 계열 최종 종료. 단 분산레짐 통찰(Track1과 이중 검증)은 자산. 이력 §10.
> 관련: §10(보완재 6 empty)·§1.1·§11. 선행: 쌍 스프레드 무조건 = NO-GO(gross +0.13%<비용 0.42%), maker = NO-GO(adverse selection).
>
> **역할 분담**: 기술 세부 assistant 자율. 사용자는 GO/NO-GO 리포트만.

## 0. 배경 — 통찰 기반, 다트 아님
Track 1 발견: 시장에 **고분산(모멘텀 잘 됨)/저분산(모멘텀 가뭄)** 두 국면. 진짜 보완재는 **저분산 국면에서 버는 것.** 쌍 스프레드 되돌림은 **반전이 실재**함이 확인됨(target 93%·승률 53%)—다만 평균 엣지(+0.13% gross)가 taker 비용(0.42%)에 못 미쳤음. **가설: 지배적 추세가 없는 저분산 장에선 상대가치가 더 깨끗이 correction돼 엣지가 커질 수 있다.**

## 1. 가설
**"쌍 스프레드 되돌림의 엣지는 저분산(무추세) 국면에서 비용(0.42%)을 넘는다."**

## 2. ★★ p-hacking 방지 (이 설계의 생명 — §11)
이건 **pairs의 2차 검정**임(1차 무조건=NO-GO). 실패한 전략에 조건을 붙이는 거라 garden-of-forking-paths 위험 최고. 방어:
- **저분산 조건·그리드를 실행 前 봉인**(결과 보고 조건 추가 금지).
- **정직한 다중검정 고지**: 이 테스트의 Bonferroni는 내부 16조합 기준이나, **pairs는 이미 1번 검정됐으므로** 한계적 통과는 **추가 회의로** 다룬다. 단일 좁은 칸만 통과하면 기각.
- **★ 국면 분리 가드**: 저분산 EV가 **같은 조합의 고분산 EV보다 뚜렷이 커야** 진짜 국면효과. 저분산≈고분산이면 "조건이 한 일 없음"=기각. 리포트에 나란히 표기.
- 저분산에서도 실패면 **깨끗이 접고** 다른 저분산 아이디어로.

## 3. 스코프 (Gate 1만)
봇 무변경. 소급 채점. pairs harness 재사용.

## 4. 메커니즘
- **스프레드·신호·청산**: pairs와 동일(`pairs_spread`·`mr_signal.zscore`·`pairs_exit`, z_stop 3.5·max_hold 48h·taker 비용 0.42% 고정). maker 아님(adverse selection로 사망).
- **★ 저분산 게이트(신규)**: 각 진입봉의 그날 시장분산이 **저분산 국면일 때만** 진입.
  - 일별 시장분산 = 유니버스 각 코인의 그날 수익률(종가/시가−1) std (Track 1 분석과 동일 정의).
  - **국면 판정 = 인과적(causal)**: 그날 분산이 **직전 30일 분산의 하위 `regime_pctile`** 미만이면 저분산. (전기간 백분위=look-ahead 회피)
- **손익**: pairs와 동일. net = spread 되돌림 − 0.42%.

## 5. 사전등록 그리드 (자율, 실행 前 봉인)
| 파라미터 | 후보 |
|---|---|
| `n` | {24, 72} |
| `z_entry` | {2.0, 2.5} |
| `z_target` | {0.5, 1.0} |
| `regime_pctile` | {0.33, 0.50} (하위 1/3 / 하위 1/2) |

= 16조합(z_stop 3.5·max_hold 48h 고정), Bonferroni 0.05/16 ≈ 0.003125. 앵커 BTC. trailing 30일 인과 백분위.

## 6. 판정 기준 (3중 AND + 국면분리 가드)
1. **수익성**: 최적 net EV > 0, 부트스트랩 P(≤0) < 0.05/16
2. **강건성**: 중앙값 EV > 0, 양수 조합 ≥60%, 최적 이웃 양수
3. **★ 국면 분리**: 최적 조합의 **저분산 EV − 고분산(나머지) EV > 0.2%p** (조건이 실제로 일함을 증명)
- 표본 게이트: 저분산 진입 ≥ 100건. 미만 잠정.
- (보완성은 저분산 조건이 곧 가뭄이라 built-in — 참고만)

셋+가드 다 통과 → GO. 아니면 NO-GO → 접고 브레인스토밍.

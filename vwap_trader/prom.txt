이전 PC에서 봇을 graceful 종료(STOP_MOMENTUM)하고 git push 한 상태다. **인계 시점 무포지션**(들고 있는 거 없음)이라 인계가 깔끔하다. 이 PC에서 재가동 전:

1. **`git pull` 먼저.** `data/state_momentum.json`에 bar_counter·cooldown이 들어 있다(현재 포지션 0). pull 안 하면 추적 어긋남.
2. **절대 두 PC에서 동시에 돌리지 말 것.** 같은 Bybit 데모 계좌를 둘이 관리하면 주문 중복·SL 충돌로 망가진다. 이전 PC 봇이 완전히 죽었는지(`Get-Process python`) 먼저 확인. **STOP_MOMENTUM 파일이 남아 있으면 지워야** 봇이 뜬다(`rm data/STOP_MOMENTUM`).
3. 시계 동기화(관리자 PowerShell): `w32tm /resync /force` — 재부팅 직후 필수(ErrCode 10002 방지).
4. 재가동: **`cd vwap_trader; .\venv\Scripts\python.exe -m vwap_trader.momentum_bot`** — ★ **`cd vwap_trader` 필수**(venv는 `vwap_trader/venv`, git root는 한 단계 위 `code/`).
5. 로그 `State loaded: 0 positions, bar≈749` 확인(인계 시점 기준, 그 사이 변동 가능).
6. **★ 정전/크래시 후면 reconcile 확인**: state 포지션 ↔ 거래소 실제오픈(`get_positions` category=linear, settleCoin=USDT)을 symbol+qty로 대조. 진입+SL은 atomic이라 orphan 무방비 아님.
7. **★ 분석 정본 주의**: 분석은 **정본 기준 누적**(corrected106 + 신규). ⚠️ **live `trades_momentum.jsonl` 원본 합은 과거 PnL버그로 오염**(예: GRASS2 가짜 −$1,798) → raw 누적 쓰지 말 것. 신규분 다수 `estimated`(거래소 정산 전 봇 추정) → `rebuild_pnl.py`로 정정 가능(단 corrected 전체 덮어써 수동보정 되돌아감, 신규 소수건은 거래소 closed-pnl 직접대조가 안전).
8. **★ 이번 PC는 Bash/PowerShell 권한 자동허용 설정됨**(`.claude/settings.local.json`의 allow에 tool-only `"Bash"`·`"PowerShell"`). 새 PC에서도 묻지 않고 실행되길 원하면 거기에 같은 두 줄 추가.

## 1. 프로젝트 개요
- **위치**: `vwap_trader/`, Windows + PowerShell, venv `vwap_trader/venv/`. **git root는 한 단계 위(`code/`)**.
- **봇**: Bybit USDT 무기한 선물 **데모 계좌**, 모멘텀 추종. **현 버전 v7**.
- **핵심 원리**: 1h봉 abs(return)이 과거 500봉 99.5%ile 초과 시 그 방향 진입 → BE+Trailing 청산.
- **현 단계**: 데이터 수집 + 손실원인 연구. 검증 임계 **200건(Go/No-Go, 현재 180)**.
- **★ Goal(철학, PLAN §1.1 필독)**: 수많은 factor 조합에서 우상향 edge를 찾는 것이나 **진짜 제약은 factor 부족이 아니라 표본 부족**(과최적화 함정). 정공법=가설 먼저→사전등록(§11)→200건 일괄검정→살아남은 것만 채택. **현 단계 미덕=조급히 factor 늘리지 말고 표본 채울 때까지 참기.** 척도는 "손절 건수↓"가 아니라 "건당 기대값↑".

## 7. 작업 원칙 (사용자 메모리 — 반드시)
- **한국어 응답**, 기술용어 영어. **객관·냉철, 맞장구 금지, 데이터 기반. 사용자 유도에 흔들리지 말고 객관 최선.**
- **★★ 쉬운 설명 — 사용자가 반복·강하게 항의**(메모리 `feedback_plain_language_strict`): 분석 설명에서 **영어 약자(consec·OI·sigret·MFE·R·arm 등) 나열 절대 금지.** 우리말로만: consec→"연속성(꾸준한 흐름이냐 단발이냐)", oi_chg→"돈 흐름(새 돈+/빠짐−)", sigret→"파도 크기(그 1시간 변동%)", MFE→"한때 최대이익", arm A/B→"본전잠금 느린/빠른 그룹", vol_ratio→"거래량 비율(평소 대비 활발도)". 정확한 수치·표는 유지하되 비유로 풀이. **브리핑 시 보유 포지션마다 거래소 실시간 미실현 손익 포함**(`feedback_briefing_include_live_pnl`).
- **분석 전 답변 금지** — 관련 파일 끝까지 읽고 로직 추적 후 단 한 번만 답. 중간에 답 바꾸기 금지.
- 3+ 파일/복잡 로직은 계획 공유 → 승인 후. **자동 커밋 금지**(명시 요청 시만). rm/force/reset은 권한 열렸어도 실행 전 확인.

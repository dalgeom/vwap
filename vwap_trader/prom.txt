**결함 3종** (`src/vwap_trader/be_counterfactual.py`, `momentum_bot.py:833-837`·`1314`):
1. **검열 7쌍(구조적)** — 실제 arm이 B면 그림자는 A(더 느슨)라 **그림자가 먼저 나갈 수 없다 = 분기 관측 원천 불가.** 하필 분기창 7쌍이 전부 여기 속하고 **전건 실제 B가 본전청산**으로 끝났다. 이건 *"빠른 본전잠금이 승자를 잘랐나"*라는 이 실험의 **핵심 질문 그 자체**인데 차이 0으로 기록됐다.
2. **순서/해상도 1쌍(배선버그 정황)** — USUSDT(실제 A, 최대이익 0.76ATR, 손절 −$51.50). 그림자 B는 0.75ATR에서 본전잠금이 걸렸고 가격이 본전선을 뚫고 손절선까지 갔으니 **그림자는 본전에서 먼저 나갔어야** 하는데 `REAL_EXIT`로 덮였다. 1분 폴링 사이에 실제 SL이 체결되면 `_log_trade`가 그림자 돌파검사 없이 강제 마감한다.
3. **★ 그림자가 봇과 다른 청산정책을 시뮬 (전건 오염, 가장 위험)** — 봇은 `exit_mode: be_trail`이라 **본전잠금 발동 후에만 추적선 가동**(`momentum_bot.py:1314`)인데, 그림자는 **추적선을 항상 가동**한다(`be_counterfactual.py:60`, 주석에 *"봇 exit_mode=trailing 가정"* — 실제 config는 `be_trail`). 그림자 SL이 체계적으로 타이트해져 **그림자 쪽 arm에 불리하게 편향된다.** ①②는 "정보를 못 담음"이지만 **③은 담은 정보가 틀림 = 게이트에 도달했다면 틀린 판정을 내렸을 것.**

**파급**: §11.1 게이트(분기 30쌍)는 관측 가능한 real=A 절반에서만 채워지는데 11일에 1쌍. 도달까지 **~10개월** → §11.1 상한(16주)에 먼저 걸려 **판정불가로 종료될 궤도**였다.

**★ 다음 세션 1순위 = 계측기 수리** (순서대로, PLAN §5.12 A 처방):
① **결함③ 먼저** — 그림자를 봇과 같은 정책으로. 근본책은 **봇 `_update_trailing_sl`과 그림자가 같은 함수를 공유**하게 만들어 정책이 갈리는 구조 자체를 없애는 것.
② 결함② — `_log_trade` 강제마감 전, 실제 청산가가 그림자 SL 너머면 **그림자는 shadow_sl에서 이탈**로 확정.
③ 결함① — real 청산 후에도 그림자를 **캔들만으로 계속 추적**(유령 포지션, 거래소 미접촉). ⚠️ 이건 되감기 백테스트가 아니라 **forward 실시간 추적**이라 §8.9+ 강등 대상 아님.

- **분석 전 답변 금지** — 관련 파일 끝까지 읽고 로직 추적 후 단 한 번만 답. 중간에 답 바꾸기 금지.
- 3+ 파일/복잡 로직은 계획 공유 → 승인 후. **자동 커밋 금지**(명시 요청 시만). rm/force/reset은 권한 열렸어도 실행 전 확인.
- **권한**: `.claude/settings.local.json`의 `permissions.defaultMode: "bypassPermissions"` — 이 프로젝트는 확인 프롬프트 없이 도구 실행(git pull로 따라옴). 단 파괴적 명령은 실행 전 구두 통지.

## 5. 데이터 규율 (사고 이력 있음 — 반드시)
- **★★ 봇 켠 채 `data/trades_momentum.jsonl`을 IDE에서 저장(Ctrl+S) 절대 금지.** 봇은 append-only로 쓰는데 IDE가 옛 버퍼로 저장하면 append·정정이 롤백된다(06-19·06-29 2회 발생). **A-3 무결성 가드**가 시작 시 자동백업(`.bak_*`, keep 10) + 종료 시 라인수 비교로 감지하지만, **감지·복구용이지 예방이 아니다.**
- **원본 `trades_momentum.jsonl`은 봇 append 외 절대 외부수정 금지**(append-only 신성화). 정정은 `data/pnl_corrections.jsonl`에 append만.
- **★ 분석 시 정본 로딩은 반드시 `from build_canonical import load_canonical`** (A-1). 이걸 안 쓰고 corrections만 적용하면 옛 106건 거래소 실측값이 빠져 **수치가 어긋난다**(실측: 정본 +$8,787 vs 직접적용 +$6,722). 리포트도 이 로더 기준.
- **equity(거래소) = 진짜 누적 / 정본 trades = 통계.** raw jsonl 누적은 과거 PnL 버그 오염이라 쓰지 말 것.

## 결정적 발견 — SL 시뮬레이션 버그

### 발견 경위
1. 봇 72시간 실행 → 거래 0건
2. 조사: 데모 계좌 API가 펀딩비를 0.01% 고정값으로 반환 (버그) → 공개 API로 수정
3. 실시장 펀딩비도 0.01% 수준 → 시장 자체가 조용한 환경
4. bandpass(0.012~0.025%) 범위로 변경해도 3년 백테스트 EV 음수
5. **원인 발견**: 원래 백테스트의 SL 시뮬레이션 오류

### 오류 내용
```python
# 원래 코드 (잘못됨): 8h 후 종가 1번만 체크
cur_price = rows[nearest_idx]["c"]
if cur_price <= pos["sl"]:
    sl_hit = True

# 현실 (Bybit SL 주문): 매 15분봉 low/high가 SL 라인에 닿으면 즉시 발동
for r in future_candles:
    if direction == "long" and r["l"] <= sl:
        sl_hit = True; break
```

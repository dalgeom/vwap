# VWAP Trader 세션 인계

## 프로젝트 위치
`c:\Users\PC\Desktop\현진\code`

## 핵심 원칙 (절대 변경 금지)
- **Simple Is Best** — 복잡한 구조 금지. 조건 최소화.
- **데이트레이딩** — 포지션은 당일 안에 청산. 최대 보유 8시간.
- **손익비 1:2** — SL:TP = 1:2 고정. 손익분기 승률 33.3%.
- **변동성 코인** — BTC/ETH 아님. 15m 기준 ATR% 높은 알트코인.
- **고정 심볼 금지** — 매일 스크리너가 그날 가장 좋은 코인을 자동 선별.

## 현재 전략 구조

### 봇 (main.py)
- 타임프레임: **15분봉**
- 진입: EMA9이 EMA21 크로스 + **ADX > 20** (추세 강도 필터)
- SL: 진입가 ± **0.5 × ATR(14)** (변동성 적응형)
- TP: 진입가 ± **1.0 × ATR(14)** → 자동으로 1:2 RR
- 최대 보유: **8시간**
- 청산: SL/TP 히트 | EMA 역크로스 | 8h 타임아웃
- 동시 포지션: 최대 1개
- 리스크: 잔고 2%, 레버리지 5x

### 스크리너 (screener.py)
- 매일 **UTC 06:00** 자동 실행
- Bybit 변동성 상위 30개 코인 스캔
- 3가지 점수로 채점 (100점 만점):
  1. 최근 7일 EMA 크로스 적중률 (50점)
  2. ADX 상승 추세 (30점)
  3. 가격 직선성 R² (20점)
- **적중률 33% 미만 자동 탈락** (손익분기 미달)
- 상위 5개 선정 → `data/selected_coins.json` 저장
- 봇이 이 파일 읽어서 오늘 거래할 심볼 자동 갱신

## 핵심 파일 구조

```
vwap_trader/
├── src/vwap_trader/
│   ├── main.py                   # 봇 메인 루프
│   ├── strategy/ema_vwap.py      # EMA 크로스 + VWAP 신호
│   ├── infra/bybit_client.py     # Bybit API (demo=True)
│   ├── core/position_sizer.py    # 2% 리스크 수량 계산
│   ├── notifier.py               # Discord 웹훅 알림
│   └── scripts/
│       ├── screener.py           # 매일 코인 선별
│       ├── backtest_ema_vwap.py  # 전략 백테스트 (필터 비교용)
│       └── backtest_volatile.py  # 변동성 코인 백테스트
├── data/
│   ├── selected_coins.json       # 오늘 거래할 코인 목록
│   └── backtest_results/         # 백테스트 결과 JSON
└── config/.env                   # API 키, DRY_RUN 설정
```

## 백테스트에서 얻은 교훈

- 적중률 33% 미만 코인: ADX가 높아도 탈락시켜야 함
